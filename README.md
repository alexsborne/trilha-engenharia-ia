# Trilha Engenheiro de IA Aplicada

Plano de estudos pessoal (2026–2029) para Engenharia de IA Aplicada, baseado nas grades da pós
"Engenharia de Software em IA Aplicada" (UNIPDS) e do "MBA em Engenharia de Software com IA" (Full Cycle):
Python, engenharia de software, ML, LLMs, RAG, MCP, agentes, IA em produção, fine-tuning e um micro-SaaS final.

O site (`docs/`) é publicado no GitHub Pages e protegido por senha (AES-GCM + PBKDF2).

Os projetos do portfólio ficam em repositórios próprios em [github.com/alexsborne](https://github.com/alexsborne).
